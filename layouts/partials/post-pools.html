{{- /* The post collections behind post-endings.html. Call this with partialCached: Hugo builds one Related index per distinct collection, so every page has to get the same collections back rather than filtering its own copy. all: every listed post, newest first (older/newer links, and related posts on a roundup) articles: all except Interesting Links roundups (related posts elsewhere) roundups: the Interesting Links term's own pages, so that a post filed under "Interesting links" counts as well as "Interesting Links" */ -}} {{- $posts := where (where site.RegularPages ".Section" "post") ".Params.skip" "ne" "true" -}} {{- $roundups := (site.GetPage "/categories/interesting-links").Pages -}} {{- return dict "all" $posts.ByDate.Reverse "articles" (complement $roundups $posts) "roundups" $roundups -}}
